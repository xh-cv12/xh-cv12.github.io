# AI 工具导航站 · 零基础建站练习

一个纯手写（HTML + CSS + JavaScript）的 AI 导航网站，带实时检索功能。
收录 **120 款 AI 工具** + **30 个 AI 资讯/学习信息源**，分两个板块切换。
**不需要安装任何软件，不需要买服务器，不需要备案，完全免费。**

---

## 一、文件都是干什么用的

| 文件 | 作用 | 你要不要改 |
|---|---|---|
| `index.html` | 页面结构：标题、Tab、搜索框、卡片区 | 想改标题、页脚时改 |
| `style.css` | 外观：配色、间距、圆角 | 想换风格时改 |
| `tools.js` | **工具数据（最常改）**，120 款 | 加/删/改工具就在这里 |
| `articles.js` | **资讯数据**，30 个信息源 | 加/删/改资讯源就在这里 |
| `app.js` | 检索、筛选、板块切换逻辑 | 熟练后再动 |
| `admin.html` | 后台管理面板页面 | 一般不用改 |
| `admin.js` | 后台逻辑（密码、增删改、导出） | 改密码时改这里 |
| `admin.css` | 后台面板样式 | 想改后台外观时改 |
| `README.md` | 就是这份说明 | — |

关系：**HTML 是骨架，CSS 是衣服，JS 是动作。**

> ⚠️ `index.html` 这个名字不能改。服务器默认只认它，改名后打开网站会显示 404。
> ⚠️ 新增了 `articles.js`，**上传时别忘了它**。少了资讯板块会白屏报错。

## 二、先在本地看看效果

**最简单的方法**：双击 `index.html`，用浏览器打开就能看。

**更推荐的方法**（后续改完刷新就能看到）：

```bash
# 进入这个文件夹
cd ai-tools-site

# 起一个本地小服务器（Python 自带，不用装）
python3 -m http.server 8000
```

然后浏览器访问 `http://localhost:8000`。
改完文件按 `Ctrl+F5` 强制刷新即可看到变化（普通刷新有时会用缓存）。

## 三、上线：三选一，都是免费的

### 方案 1：Vercel（最省事，推荐 ⭐）

1. 把这六个文件压缩成 zip 备用
2. 打开 [vercel.com](https://vercel.com) → 用 GitHub 账号登录
3. 点 **Add New → Project**
4. 如果是第一次用，选模板 **Other → Deploy without Git**，把整个文件夹拖进去
5. 等十几秒，会得到一个 `xxx.vercel.app` 的网址，全球可访问

**优点**：自动 HTTPS、全球 CDN 加速、国内访问比 GitHub Pages 快。

### 方案 2：GitHub Pages（完全免费，适合顺便学 Git）

1. 注册 [github.com](https://github.com)，点右上角 **+ → New repository**
2. 仓库名填 `你的用户名.github.io`（**必须这样填**，例如 `zhangsan.github.io`）
3. 勾选 Public，点 Create repository
4. 在仓库页点 **Add file → Upload files**，把 6 个文件拖进去，点 Commit
5. 进 **Settings → Pages**，`Source` 选 `Deploy from a branch`，分支选 `main`，点 Save
6. 等 1–3 分钟，访问 `https://你的用户名.github.io`

> 仓库名如果不是 `用户名.github.io`，网址会变成 `用户名.github.io/仓库名`。

### 方案 3：Netlify Drop（连账号都可以不要）

打开 [app.netlify.com/drop](https://app.netlify.com/drop)，把文件夹拖进网页，立刻上线。
适合临时演示，网址随机，建议注册账号后改个好记的名字。

## 四、怎么加内容

### 加一个新工具

打开 `tools.js`，照着已有条目抄一个，改掉内容即可：

```js
{
  name:  "工具名",
  desc:  "一句话说明它能干什么",
  cat:   "图像生成",              // 必须是 CATEGORIES 里已有的分类
  tags:  ["标签1", "标签2"],       // 搜索时能命中
  url:   "https://官网地址",
  price: "免费",                   // 免费 / 免费+付费 / 付费
},
```

### 加一个资讯源

打开 `articles.js`，同样抄一条：

```js
{
  name:     "资讯源名称",
  desc:     "这个源主要讲什么、适合谁看",
  platform: "公众号",      // 公众号 / 网站 / 邮件订阅 / 社区
  cat:      "中文资讯",    // 必须是 ARTICLE_CATS 里的分类
  freq:     "日更",        // 日更 / 周更 / 不定期
  wx:       "QbitAI",      // 可选：公众号 ID，卡片右下角会显示"微信搜：xxx"
  tags:     ["标签1", "标签2"],
  url:      "https://官网地址",
},
```

> 💡 **为什么收录的是「信息源」而不是「单篇文章」？**
> 单篇文章的链接过几个月就失效了，而公众号、官网、Newsletter 不会。
> 想加具体文章也行，把 `name` 换成文章标题、`freq` 换成发布日期即可。

### 加新分类

两个文件顶部各自有个分类数组，往里加字符串即可：

```js
// tools.js
const CATEGORIES = ["全部", "对话助手", "图像生成", /* 在这里加 */];

// articles.js
const ARTICLE_CATS = ["全部", "中文资讯", "国际资讯", /* 在这里加 */];
```

> ⚠️ 加分类后记得至少放一条数据进去，否则点这个分类会显示空列表。

## 五、后台管理（可视化增删改）

### 怎么进

三种方式，任选：

1. 首页页脚最下方那个很淡的 **⚙** 图标
2. 在首页按 **Ctrl + Shift + A**
3. 直接访问 `你的网址/admin.html`

密码：**`123`**

### 能做什么

- 新增 / 编辑 / 删除工具或资讯源
- 按名称、分类搜索，快速定位
- 一键**导出代码**，生成可直接覆盖的 `tools.js` / `articles.js`
- 一键**恢复默认**（丢弃所有本地改动）

### ⚠️ 必须理解的两件事

**1. 这个密码挡不住懂技术的人。**
密码写在 `admin.js` 里，任何人按 F12 输入 `atob("MTIz")` 就能看到明文。
静态网页没有后端，做不到真正的密码保护——它只防误触，不防攻击者。
**别用它保护任何真正敏感的内容。**

**2. 后台改动只存在你自己浏览器里，别人看不到。**
改完首页顶部会出现一条提示：「当前显示的是本地修改版」。
要让改动对所有访客生效，必须：

> 后台点「导出代码」→ 下载 `tools.js` / `articles.js` → 上传到 GitHub 覆盖原文件 → 等 1 分钟

### 改密码

打开 `admin.js`，最上面几行：

```js
const PWD_ENCODED = btoa('123');   // 把 123 换成你想要的密码
```

`btoa` 会把字符串编码，所以直接改引号里的内容即可，不用自己算编码值。

## 七、下一步可以练什么

按难度递增，每做完一个你对前端的理解就扎实一层：

1. **改配色** —— 改 `style.css` 顶部的 `--brand` 变量，全站主题色立刻变
2. **加一个「热门推荐」置顶区** —— 给数据加个 `hot: true` 字段，渲染时排到前面
3. **加相关度排序** —— 现在结果是按数据顺序排的，可以改成：名称命中的排最前，标签命中次之，描述命中最后
4. **卡片显示访问次数** —— 用 `localStorage` 记录点击
5. **加详情页** —— 点卡片不跳转官网，而是打开自己的介绍页
6. **接一个真实搜索后端** —— 几十个工具之后，前端过滤会不够用

## 八、常见问题

**Q：打开是 404？**
主页文件必须叫 `index.html`，且要放在仓库根目录，不能放在子文件夹里。

**Q：改了 CSS 没变化？**
按 `Ctrl+F5` 强制刷新，浏览器缓存了旧文件。

**Q：后台改了内容，别人访问为什么看不到？**
后台改动存在你自己浏览器里，只对你生效。要点「导出代码」下载文件，再上传到 GitHub，才对所有人生效。

**Q：换了台电脑，后台改的内容没了？**
对，本地改动跟着浏览器走。这也是为什么重要改动一定要导出并上传。

**Q：手机上排版乱了？**
检查 `index.html` 里有没有这行，没有的话手机上会缩成一团：
```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

**Q：需要备案吗？**
GitHub Pages / Vercel 的服务器都在境外，**不需要备案**。只有用中国大陆的服务器才需要。

**Q：可以绑自己的域名吗？**
可以。买域名后，在 Vercel / GitHub Pages 的设置里填域名，再按提示去域名商那里加一条 DNS 解析记录即可，平台都提供免费 HTTPS 证书。
